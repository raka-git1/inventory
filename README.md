# Smart Inventory Management System

Admin dashboard sederhana untuk mengelola produk dan stock.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Supabase
- Prisma
- Vercel

## Fitur

- Login admin sederhana
- Dashboard inventory
- Total produk
- Total stock
- Nilai inventory
- Low stock alert
- Grafik stock
- Tambah produk
- Hapus produk
- Stock In
- Stock Out
- Pencarian produk
- Dark/light mode
